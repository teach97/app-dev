1일차 · 조회 기능

GET 요청으로 도서 데이터를 조회해 보는 실습

6개 실습
01

서버 상태

서버가 정상적으로 실행 중인지 확인해.

 02

도서 목록

등록된 모든 도서를 목록으로 확인해.

 03

도서 단건 조회

도서 번호로 책 한 권을 조회해.

 04

도서 검색

제목 키워드가 포함된 도서를 검색해.

 05

저자 필터·정렬

저자로 필터링하고 연도순으로 정렬해.

 06

페이지네이션

이전·다음 버튼으로 목록을 나눠서 봐.

2일차 · 등록과 검증

POST 요청으로 데이터를 등록하고 오류를 처리하는 실습

6개 실습
07

도서 등록

제목, 저자, 연도를 입력해 새 도서를 등록해.

 08

검증 오류 표시

잘못된 입력값을 화면에 오류로 표시해.

 09

등록 후 목록 갱신

도서를 등록하면 목록을 자동으로 새로고침해.

 10

404 오류 처리

없는 도서를 조회했을 때 안내 메시지를 보여줘.

 11

태그·출판사 등록

리스트와 객체가 포함된 중첩 데이터를 보내.

 12

최종 통합 실습

등록, 목록, 201·409·422 오류를 한 번에 처리해.
